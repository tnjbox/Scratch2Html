一、什麼是 Heuristic Search？

啟發式搜尋就是：

搜尋時，不是亂試，而是「先試看起來比較好的選擇」

  • DFS：一路走到底（不管好不好）
  • BFS：全部一層一層試（很花力氣）
  • Heuristic Search：有方向感地試

二、為什麼要用 A* 演算法？

  • 因為它把「目前走得多好」與「未來看起來好不好」一起考慮
  • 是最經典、也最容易理解的啟發式搜尋

f(n) = g(n) + h(n)

  • g(n)：目前已經拿到多少金幣
  • h(n)：附近「可能再拿到多少金幣」

四、A* 演算法程式碼（教學註解版）

function runAStar(){ // open list：尚未探索，但「有希望」的節點 // 每個節點包含： // r, c → 目前位置 // coins → 已累積的金幣 // path → 走過的路徑（避免重複） let open = [{ r: start.r, c: start.c, coins: 0, path: [{r:start.r, c:start.c}] }]; let best = null; // 當還有候選節點，就持續搜尋 while(open.length > 0){ // 🔑 核心：依 f(n)=g(n)+h(n) 排序 // g(n) = coins // h(n) = heuristic(附近金幣) open.sort((a,b)=> (b.coins + heuristic(b.r,b.c)) - (a.coins + heuristic(a.r,a.c)) ); // 取出「最有希望」的節點 const cur = open.shift(); // 若已達步數上限（15步 → 16格），停止 if(cur.path.length >= 16){ best = cur; break; } // 嘗試四個方向 for(const d of dirs){ const nr = cur.r + d.r; const nc = cur.c + d.c; // 邊界判斷 if(nr<0||nr>=SIZE||nc<0||nc>=SIZE) continue; // 不可重複走格子（避免刷分） if(cur.path.some(p=>p.r===nr && p.c===nc)) continue; // 將新節點加入 open list open.push({ r:nr, c:nc, coins: cur.coins + map[nr][nc], path: [...cur.path, {r:nr, c:nc}] }); } } // best 就是 A* 找到的最佳解 }
🔑 教學重點一句話：
A* 不是全部試，而是每一步都問「哪條路最有希望？」
