🧭 第1週：地圖與隨機金幣生成

🎯 學習目標

  • 認識什麼是陣列（Array）
  • 了解亂數（Random）的概念
  • 使用程式生成 7×7 的隨機金幣地圖

📘 一、什麼是陣列？

陣列就像「學校的置物櫃」，每一格都有編號，可以放資料。 例如 7 個班級的分數：

let score = [80, 75, 90, 88, 95, 70, 60];
console.log(score[0]); // 顯示第一個班級的分數：80
console.log(score[4]); // 顯示第五個班級的分數：95

🎲 二、什麼是亂數？

亂數是電腦隨機產生的數字。

let x = Math.random(); // 產生 0~1 間的亂數
console.log(x);

若要產生 -3 ~ 3 之間的整數，可這樣寫：

let coin = Math.floor(Math.random() * 7) - 3;

🗺️ 三、7×7 金幣地圖生成程式

每個格子代表一個座標，裡面存放隨機的金幣數（可能是負數）。 中央位置 (3,3) 為主角出發點，金幣值固定為 0。

// 建立 7x7 地圖，每格隨機產生 -3 ~ 3 金幣 const SIZE = 7; let map = []; const startRow = 3; const startCol = 3; for (let i = 0; i < SIZE; i++) { let row = []; for (let j = 0; j < SIZE; j++) { let coin = Math.floor(Math.random() * 7) - 3; row.push(coin); } map.push(row); } // 中央位置固定為 0，表示出發點 map[startRow][startCol] = 0;
