🔍 第4週：從窮舉搜尋（Brute Force）到 DFS 全搜尋找最大金幣路徑

📘 一、先認識窮舉搜尋（Brute Force）

在「找金幣」這題中，主角每一步可以往 上、下、左、右 走。 如果我們想要「一定找到最多金幣的走法」，最直覺的方法就是：

把所有可能路線都試一次 → 比較哪一條金幣最多。

🧠 為什麼窮舉會爆炸？

  • 每一步最多有 4 種選擇（上/下/左/右）
  • 最多走 15 步 → 可能路線數量大約是 415

415 = 1,073,741,824（超過 10 億！）
這種「選擇數量快速爆炸」的現象叫做 爆炸性成長。在實務上不實用。

✅ 本週重點：我們改用 DFS 的「遞迴 + 回溯」方式，把所有可能路線用更有結構的方法走完， 同時記錄目前最好的答案。

💡 二、什麼是 DFS（深度優先搜尋）？

DFS（Depth-First Search）是一種搜尋方法，它的特色是：

先選一條路一路走到底 → 走不下去就退回（回溯）→ 再換另一條路。

🧩 DFS 的 3 個核心概念

  1. 遞迴（Recursion）：函式呼叫自己，繼續往下一步。
  2. 回溯（Backtracking）：走到底後，把「做過的選擇撤銷」，回到岔路換方向。
  3. 全搜尋：把所有可能都試過，最後一定能找出最佳解。

🏫 生活比喻

像走迷宮：先走某條路走到底，遇到死路再回頭，換另一條岔路繼續。

🪙 三、把 DFS 套用到「找金幣」題目：程式碼怎麼寫？

✅ DFS 需要記錄哪些「狀態」？

  • 目前位置：row, col（主角在哪裡）
  • 剩餘步數：stepsLeft（最多 15 步，每走一步就 -1）
  • 累積金幣：coins（目前走到這裡拿到多少）
  • 是否走過：visited（避免同一格一直來回刷）
  • 目前路徑：path（用來記錄最佳路線）

💻 DFS 教學用核心程式碼片段

function dfs(row, col, stepsLeft, coins, path) { // ① 終止條件：步數用完，更新最大值 if (stepsLeft === 0) { if (coins > maxCoin) { maxCoin = coins; // 記錄最大金幣 bestPath = path.slice(); // 記錄最佳路徑（複製） } return; } // ② 嘗試四個方向：上、下、左、右 for (let dir of directions) { let nr = row + dir.r; let nc = col + dir.c; // ③ 邊界檢查：不能走出地圖 if (nr < 0 || nr >= SIZE || nc < 0 || nc >= SIZE) continue; // ④ 避免重複：走過的格子不再走 if (visited[nr][nc]) continue; // ⑤ 前進（做選擇） visited[nr][nc] = true; path.push({r:nr, c:nc}); // ⑥ 遞迴：繼續往下一步走 dfs(nr, nc, stepsLeft-1, coins + map[nr][nc], path); // ⑦ 回溯：撤銷選擇，回到上一層 path.pop(); visited[nr][nc] = false; } }
🔑 教師講解抓重點： 「做選擇 → 遞迴往下 → 回溯撤銷」就是 DFS 的靈魂。
