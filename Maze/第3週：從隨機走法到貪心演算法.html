📘 一、概念介紹

電腦在決定「下一步」的行動時，可以有不同策略：

  • 隨機走法： 電腦亂選方向，就像盲目探索。
  • 貪心走法： 電腦會觀察上下左右四格，走向金幣最多的那一格。

💻 二、程式碼教學區

🎲 隨機走法的主角移動程式

隨機走法是讓電腦每次亂挑一個方向，往那邊走一步：

// 隨機走法主要邏輯
const directions = [
  { r: -1, c: 0 }, // 上
  { r: 1, c: 0 }, // 下
  { r: 0, c: -1 }, // 左
  { r: 0, c: 1 } // 右
];
let dir = directions[Math.floor(Math.random() * 4)]; // 隨機挑一個
let newRow = player.row + dir.r;
let newCol = player.col + dir.c;
moveTo(newRow, newCol); // 嘗試移動主角

🤔 貪心走法的主角移動程式

貪心走法會檢查上下左右四格，挑出「金幣最多」的那格：

// 貪心走法主要邏輯
const directions = [
  { r: -1, c: 0 }, { r: 1, c: 0 },
  { r: 0, c: -1 }, { r: 0, c: 1 }
];
let bestMove = null;
let bestCoin = -Infinity;

for (let dir of directions) {
  let nr = player.row + dir.r;
  let nc = player.col + dir.c;
  if (nr < 0 || nr >= SIZE || nc < 0 || nc >= SIZE) continue; // 邊界檢查
  if (map[nr][nc] > bestCoin) {
    bestCoin = map[nr][nc];
    bestMove = { r: nr, c: nc };
  }
}
moveTo(bestMove.r, bestMove.c); // 往金幣最多的方向走

💬 教師講解建議： 可以請學生觀察兩段程式碼，思考：

  • 隨機走法用「亂數」選方向 → Math.random()
  • 貪心走法用「比較大小」挑最佳 → if (map[nr][nc] > bestCoin)
